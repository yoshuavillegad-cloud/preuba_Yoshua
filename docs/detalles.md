
# Guía complementaria de ciberseguridad

## 1. Contraseñas y autenticación multifactor

Una contraseña segura debe ser larga, difícil de adivinar y distinta de las que se usan en otros servicios. Un gestor de contraseñas facilita guardar credenciales únicas.

La **autenticación multifactor (MFA)** añade una segunda comprobación, por ejemplo una aplicación de autenticación o una llave de seguridad.

## 2. Actualizaciones

Las actualizaciones corrigen errores y vulnerabilidades conocidas. Conviene instalar las actualizaciones del sistema operativo, del navegador y de los programas que utilizamos habitualmente.

## 3. Copias de seguridad

Una copia de seguridad permite recuperar datos si el equipo falla, se pierde o sufre un ataque.

Es recomendable conservar más de una copia y mantener al menos una desconectada del equipo principal.

## 4. Cómo reconocer un posible phishing

- El mensaje crea urgencia o amenaza con bloquear una cuenta.
- La dirección del remitente no coincide con la organización que dice representar.
- El enlace lleva a un dominio extraño o con errores tipográficos.
- Solicita contraseñas, códigos de verificación o datos bancarios de forma inesperada.

Ante la duda, no pulses el enlace. Entra en el servicio escribiendo tú mismo la dirección oficial en el navegador.
